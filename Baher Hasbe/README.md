**Bahire Hasab API** is a high-performance RESTful JSON service designed to calculate Ethiopian Orthodox Tewahedo Church liturgical dates, fasts, and movable feasts.

---

## 🇪🇹 Overview
The Ethiopian Calendar (Bahire Hasab) is based on a unique chronological system. This API automates the complex mathematical algorithms required to determine dates for annual events such as:
*   **Nenewe (Fast of Nineveh)**
*   **Abiy Tsom (Great Lent)**
*   **Tinsae (Easter)**
*   **And all other movable feasts...**

The engine uses **Real-time Computational Logic** (not static tables), ensuring accuracy for any given Ethiopian year.
